# ระบบเว็บไซต์โรงพยาบาลโคกศรีสุพรรณ (KSP Web Hospital)

ระบบเว็บไซต์หลักและระบบจัดการเนื้อหา (CMS) โรงพยาบาลโคกศรีสุพรรณ จังหวัดสกลนคร พัฒนาด้วยเทคโนโลยี Frontend มาตรฐาน ร่วมกับ Node.js Backend

---

## 🌟 ฟีเจอร์หลัก
1. **หน้าเว็บประชาสัมพันธ์และบริการทางการแพทย์:**
   - ค้นหาแพทย์และตารางออกตรวจ (`pages/find-doctor.html`)
   - ศูนย์การแพทย์เฉพาะทางและคลินิก (`pages/centers.html`)
   - แพ็กเกจตรวจสุขภาพและโปรโมชัน (`pages/packages.html`)
   - คู่มือผู้รับบริการและสิทธิการรักษา (`pages/patient-guide.html`)
   - บทความสุขภาพและสาระน่ารู้ (`pages/articles.html`)
   - นัดหมายแพทย์ออนไลน์ (`pages/appointment.html`)
   - ข้อมูลติดต่อโรงพยาบาลและแผนที่นำทาง (`pages/contact.html`)
2. **ระบบบริหารจัดการเนื้อหาหลังบ้าน (CMS):**
   - เข้าสู่ระบบจัดการหลังบ้านผ่าน `pages/login.html`
   - แดชบอร์ดจัดการข้อมูลผ่าน `pages/admin.html`
   - จัดเก็บข้อมูลด้วย Node.js JSON Database อัตโนมัติในโฟลเดอร์ `data/`
3. **ระบบ Auto-Update ผ่าน GitHub:**
   - มีปุ่มตรวจเช็คเวอร์ชันและกดอัปเดตจาก GitHub ได้ทันทีที่มุมขวาล่างของเว็บไซต์
   - รองรับการรีสตาร์ท Process อัตโนมัติผ่าน PM2 บนเซิร์ฟเวอร์

---

## 🚀 วิธีการติดตั้งและรันระบบ

### 1. รันบนเครื่องคอมพิวเตอร์ทั่วไป (Localhost)
```bash
# ติดตั้งและเริ่มทำงานผ่าน Node.js
npm start
# หรือ
node server.js
```
เปิดใช้งานผ่านเว็บเบราว์เซอร์: `http://localhost:3088`

### 2. รันบนเซิร์ฟเวอร์จริง (Production Linux Server)
- **เครื่องเซิร์ฟเวอร์:** `192.168.2.202`
- **พาธโฟลเดอร์:** `/opt/ksp-web`
- **พอร์ตบริการ:** `3088`
- **ควบคุมการทำงานด้วย PM2:**
```bash
pm2 start server.js --name "ksp-web"
pm2 save
```
