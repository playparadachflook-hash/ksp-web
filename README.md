# ระบบเว็บไซต์โรงพยาบาลโคกศรีสุพรรณ (KSP Web Hospital)

ระบบเว็บไซต์หลักและระบบจัดการเนื้อหา (CMS) โรงพยาบาลโคกศรีสุพรรณ พัฒนาด้วยเทคโนโลยี **Node.js (Express Framework) & EJS Views**

---

## 🔒 มาตรฐานความปลอดภัย (Security Features)
1. **ระบบ Clean URLs (ไม่มี .html ใน URL):**
   - ทุกหน้าใช้งานผ่าน Route สะอาด เช่น `/`, `/admin`, `/login`, `/departments`, `/contact`
   - มีระบบความปลอดภัยตรวจจับและป้องกัน: หากมีผู้ใช้งานหรือบอทพยายามเรียก URL ที่ลงท้ายด้วย `.html` หรือเรียกตรงไปยังไฟล์ ระบบจะทำ 301 Security Redirect ไปยัง Clean URL ทันที
2. **ไม่เปิดเผยโครงสร้างไฟล์ใน Root:**
   - แปลงไฟล์หน้าเว็บเป็น EJS Templates ในโฟลเดอร์ `views/` ทั้งหมด
   - ลบไฟล์ `.html` และไฟล์ `.php` ออกจากระบบ 100%
   - เสิร์ฟเฉพาะโฟลเดอร์ Assets ที่จำเป็น (`/css`, `/js`, `/assets`)

---

## 🌟 แผนผังเส้นทาง (Clean Routes)
- `/` : หน้าแรกโรงพยาบาล
- `/departments` : แผนกและคลินิก
- `/rooms` : ห้องพักผู้ป่วย
- `/medical-documents` : ขอเอกสารทางการแพทย์
- `/facilities` : สิ่งอำนวยความสะดวก
- `/news` : ข่าวสาร & กิจกรรม
- `/downloads` : ดาวน์โหลดเอกสาร
- `/internal-websites` : เว็บไซต์ภายใน / ระบบสารสนเทศ
- `/about-general` : ข้อมูลทั่วไปโรงพยาบาล
- `/vision-mission` : วิสัยทัศน์และพันธกิจ
- `/quality-awards` : มาตรฐานคุณภาพและรางวัลรับรอง
- `/policy` : ประกาศนโยบายโรงพยาบาล
- `/contact` : ข้อมูลติดต่อและแผนที่นำทาง
- `/login` : เข้าสู่ระบบจัดการหลังบ้าน
- `/admin` : แดชบอร์ดจัดการเนื้อหา (CMS)
